# Agent Schema Registry

MrCakes931 Agent Intelligence Ecosystem · Contract layer

A versioned catalog of JSON Schemas and compatibility rules for manifests, messages, identities, and audit records.

## Scope
- JSON Schema Draft 2020-12 as the default schema dialect.
- Stable schema identifiers and explicit versioning.
- Positive and negative examples.
- Compatibility guidance for additive and breaking changes.

## Current status
Scaffolded, version 0.1.0. Initial common metadata schema: [schemas/common/metadata.schema.json](schemas/common/metadata.schema.json). See [docs/SCHEMA-REGISTRY.md](docs/SCHEMA-REGISTRY.md).

Schema validity does not establish truth, safety, authorization, or semantic correctness.
