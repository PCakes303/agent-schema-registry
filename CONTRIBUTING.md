# Contributing

1. Read README.md, AGENTS.md, and the relevant documents under docs/.
2. Keep requirements, contracts, examples, implementation, and tests traceable.
3. Make the smallest coherent change; document compatibility impact.
4. Add or update automated tests for behavior and schema changes.
5. Never commit secrets, private ecosystem material, or unlicensed third-party content.
6. Describe validation performed and any limitations in the pull request.

The master registry is authoritative for ecosystem-wide inventory and dependency metadata; this repository is authoritative for its own implementation.
